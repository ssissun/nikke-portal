# NIKKE Portal

승리의 여신: 니케 유저들이 자주 쓰는 사이트를 한 화면에서 여는 모음 페이지입니다.

주소: https://ssissun.github.io/nikke-portal/

예전 주소(https://ssissun.github.io/nikke-hub/)로 들어와도 새 주소로 자동 이동합니다.

## 사용법

### 사이트 열기

- 왼쪽 메뉴에서 사이트를 고르면 이 화면 안에 열립니다 (모바일은 왼쪽 위 ☰ 로 메뉴 열기)
- 모바일 화면 아래 탭은 홈 + 5칸 바로가기로, 즐겨찾기가 먼저 들어가고 남는 칸은 시프티패드 → 딜도로 → 모듈작 → 소장품 → 버충간단 순으로 채워집니다
- `새 탭` 표시가 붙은 사이트는 다른 사이트 안에 표시되는 것을 막고 있어서 새 탭으로 열립니다
- 한 번 연 사이트는 다른 메뉴로 갔다 와도 입력하던 내용이 그대로 남아 있습니다

### 상단 버튼

| 버튼 | 기능 |
|---|---|
| ☰ | PC: 사이드바 접기·펴기 / 모바일: 메뉴 열기 |
| 🔍 (`Ctrl+K`) | 사이트 이름·카테고리로 검색 (↑↓ 로 고르고 Enter) |
| ☀ / ☾ | 라이트·다크 테마 전환 (처음에는 기기 설정을 따름) |
| ☆ | 지금 보는 사이트를 즐겨찾기에 추가·해제 |
| ◫ / ⊟ | 두 사이트 좌우 / 위아래 나란히 보기. 같은 버튼을 다시 누르면 닫기, 다른 버튼을 누르면 방향 전환. ⇄(⇅) 자리 바꾸기 · ✕ 닫기. 경계선을 드래그하면 크기 조절, 더블클릭하면 반반. 한 칸이 380px 이상 나오는 방향만 켜지고, 창이 작아 안 되는 방향은 흐리게 표시 (휴대폰에서는 숨김) |
| ⟳ | 지금 보는 사이트만 새로고침 |
| ↗ 새 탭 | 지금 보는 사이트를 새 탭으로 열기 |

### 즐겨찾기 · 최근 · 마지막 화면

- 즐겨찾기 추가·해제: 상단 ☆ 또는 메뉴에서 사이트 이름 오른쪽 ☆ (PC는 그 줄에 마우스를 올리면 보임). 메뉴의 ☆는 사이트를 열지 않고 즐겨찾기만 바꿉니다
- 즐겨찾기는 메뉴 맨 위와 홈 첫 줄에 모이고, 모바일에서는 화면 아래 탭 앞쪽에 나옵니다 (5개까지)
- 최근 본 사이트가 메뉴 위쪽에 4개까지 보입니다
- 다시 열면 마지막에 보던 사이트로 시작합니다 (홈에서 닫으면 홈으로 시작)

### 내 사이트 추가

1. 메뉴 맨 아래 `내 사이트` 옆 `+ 추가` (또는 홈의 `+ 사이트 추가`)
2. 이름과 주소 입력
3. 이 화면 안에 안 뜨는 사이트라면 `새 탭으로 열기` 체크
4. 삭제는 메뉴에서 이름 옆 ✕

### 저장 데이터 연동 (선택, PC)

화면 안에 띄운 사이트는 브라우저 정책상 원래 사이트와 저장 데이터가 따로 관리됩니다. 예를 들어 버충 계산기 (간단)에 저장해 둔 덱이 포털 안에서는 보이지 않습니다. 사용자 스크립트를 설치하면 포털 안에서도 원래 사이트와 같은 데이터를 씁니다.

설치

1. 브라우저에 [Tampermonkey](https://www.tampermonkey.net/) 또는 [Violentmonkey](https://violentmonkey.github.io/) 설치
   - Chrome·Edge는 확장 프로그램 관리에서 Tampermonkey의 `사용자 스크립트 허용`(또는 개발자 모드)을 켜야 합니다
2. [nikke-portal-sync.user.js](https://ssissun.github.io/nikke-portal/nikke-portal-sync.user.js) 를 열고 `설치`
   - 설치 화면에 `모든 사이트에서 실행`으로 나옵니다. 내 사이트까지 연동하기 위해서이고, 실제로는 포털 안에서 한 번이라도 연 사이트에서만 동작합니다
3. 포털에서 연동할 사이트를 한 번 열기
4. **원래 사이트에 직접 한 번 들어가기** — 이때 원래 사이트의 데이터가 연동용으로 올라갑니다
5. 포털에서 그 사이트를 ⟳ 새로고침

동작 방식

- 원래 사이트 쪽 데이터가 기준입니다. 설치 후 포털을 먼저 열어도 원래 사이트 데이터는 덮이지 않습니다
- 처음 연동할 때 포털 안에만 있던 값은 원래 사이트 값으로 바뀌고, 바뀌기 전 값은 백업으로 남습니다
- 버충 계산기 (간단)의 저장 덱은 덱 단위로 합칩니다. 포털에서만 저장한 덱도 사라지지 않고 양쪽에 모두 보입니다
- 한쪽에서 바꾼 값은 다른 쪽을 새로고침하면 보입니다 (포털은 ⟳)
- 양쪽에서 같은 값을 동시에 바꾸면 원래 사이트 쪽 값이 남고, 다른 쪽 값은 백업으로 남습니다
- 백업 되살리기: 그 사이트를 열고 Tampermonkey 메뉴 → `백업 복원` → 번호 입력. 덮어써지는 지금 값도 새 백업으로 남습니다 (최근 20개 보관)

한계

- 브라우저 localStorage에 저장하는 데이터만 연동합니다. 로그인 상태와 이름에 token·auth·session 등이 들어간 값은 옮기지 않습니다
- 대상 사이트: 포털 안에서 열리는 사이트 전부 (내 사이트 포함). 시프티패드, 아카라이브·디시 글, 패키지 효율표 시트는 직접 접속이 잦고 저장 데이터가 커서 연동하지 않습니다
- 저장 방식(localStorage)을 확인한 사이트는 버충 계산기 (간단)뿐이고, 나머지는 사이트가 localStorage에 저장하는 경우에만 연동됩니다
- 모바일은 Android Firefox + 확장 정도에서만 쓸 수 있습니다

## 알아 두기

- 즐겨찾기·내 사이트 등은 **이 브라우저에만** 저장됩니다. 다른 기기·브라우저에서는 따로 설정해야 합니다
- 화면 안에 띄운 사이트는 원래 사이트에 직접 들어갔을 때와 로그인·저장 데이터가 분리될 수 있습니다. 로그인이 풀리거나 저장한 값이 안 보이면 `↗ 새 탭` 으로 열거나 [저장 데이터 연동](#저장-데이터-연동-선택-pc)을 설치하세요
- 각 사이트의 내용과 권리는 해당 사이트 운영자에게 있습니다
